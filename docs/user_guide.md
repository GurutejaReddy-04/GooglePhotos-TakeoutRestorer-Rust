# User Guide (GUI)

## Starting the App
Double-click the Restorer application icon to launch the GUI.

## Restoring Photos
1. Click **Select Takeout Directory** and choose the folder containing your unzipped Google Photos Takeout `.zip` or uncompressed directory.
2. Click **Select Output Directory** to choose where the restored photos should be copied.
3. Click **Start Processing**.

## Monitoring Progress
The dashboard will display:
- Real-time file processing logs.
- Estimated Time to Completion (ETA).
- Processing speed (files/second).

You may click **Pause** at any time to temporarily halt execution, or **Cancel** to abort entirely.
