# Security Policy

## Supported Versions

Only the current major version is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| 0.x.x   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities by creating a Private Security Advisory on GitHub. Do not file public issues for zero-day vulnerabilities. 
We will respond within 48 hours.
